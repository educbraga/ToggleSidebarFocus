ToggleSidebarFocus 1.1.0
========================

One shortcut to show, focus and hide the sidebar.

What's new
- Command Palette: run "View: Toggle SideBar and Focus" without setting up
  a key binding first.
- Windows with no folder open: the sidebar now shows your open files
  instead of staying hidden.

Key binding
Open Preferences > Key Bindings and add:

    { "keys": ["super+enter"], "command": "toggle_sidebar_and_focus" }

Thanks to Andrew Davis for both improvements.
